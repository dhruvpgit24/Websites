A full-stack Node.js application where users can register, login, and create posts.  
Users can also like/unlike posts, edit or delete their own posts — all while maintaining secure authentication using JWT.

Built with **Express.js, MongoDB, EJS**, and styled beautifully with **CSS**.

---

## 🚀 Features

- ✅ User Registration & Login  
- 🔐 Password Hashing with Bcrypt  
- 🍪 Cookie-based Authentication (JWT)  
- 🖊️ Create, Edit, and Delete Posts  
- ❤️ Like and Unlike Posts  
- 🧑 Personalized Profile Page with Profile Image Upload (via Multer)  
- 🎨 Clean and Responsive UI (EJS + CSS)
